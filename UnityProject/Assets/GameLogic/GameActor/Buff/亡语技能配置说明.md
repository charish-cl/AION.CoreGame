# 亡语技能配置说明

## 技能描述
"PropSkinLevel10202_1": "[新卡片] 亡语：死亡时有<color=#00ff00>25%</color>概率使<color=#00ff00>2</color>名敌人中毒，每<color=#00ff00>0.8</color>秒受到剑兵攻击力<color=#00ff00>20%</color>的伤害，持续<color=#00ff00>4</color>秒"

## 配置方案

这个技能需要配置两个Buff：

### 1. 亡语Buff（死亡触发，概率25%，对2名敌人施加中毒Buff）

**Buff配置：**
- **Id**: 例如 `10001`
- **Name**: "亡语-中毒"
- **Desc**: "死亡时有25%概率使2名敌人中毒"
- **BuffType**: `Status` (4)
- **TargetType**: `Enemy` (2)
- **TriggerType**: `OnDeath` (5)
- **StatusId**: 0
- **ConditionParams**: `[]` (空)
- **ValueParams**: `[中毒BuffId, 2, 999, 2, 1]`
  - `中毒BuffId`: 中毒Buff的ID（例如10002）
  - `2`: 目标数量
  - `999`: 搜索半径（很大的值，表示全图搜索）
  - `2`: TargetType (Enemy)
  - `1`: UseAttackerNumeric (true，使用攻击者的数值组件)
- **Duration**: `0` (死亡时立即触发，不需要持续时间)
- **TickInterval**: `0`
- **MaxStacks**: `1`

**注意**: 由于是概率触发，需要在ValueParams的第一个位置设置概率值。但这里我们使用OnDeath触发类型，概率值应该通过ConditionParams或单独的概率字段设置。

**修正后的ValueParams**: `[0.25, 中毒BuffId, 2, 999, 2, 1]`
  - `0.25`: 概率值（25%）
  - `中毒BuffId`: 中毒Buff的ID
  - `2`: 目标数量
  - `999`: 搜索半径
  - `2`: TargetType (Enemy)
  - `1`: UseAttackerNumeric

**但是**，根据代码实现，ApplyBuffEffectParams的参数顺序是：
- `BuffId` (int)
- `TargetCount` (int)
- `SearchRadius` (float)
- `UseAttackerNumeric` (bool)

而概率值应该通过BuffConfig的Probability字段设置，或者通过ConditionParams设置。

**最终配置方案**：

**亡语Buff (ID: 10001)**:
- **BuffType**: `Status` (4)
- **TargetType**: `Enemy` (2)
- **TriggerType**: `OnDeath` (5)
- **ValueParams**: `[0.25, 10002, 2, 999, 2, 1]`
  - `0.25`: 概率值（25%，可选，如果设置了会在BuffCmp中处理）
  - `10002`: 中毒Buff的ID
  - `2`: 目标数量
  - `999`: 搜索半径（全图搜索）
  - `2`: TargetType (Enemy，可选，默认Enemy)
  - `1`: UseAttackerNumeric (true，使用攻击者的数值组件)
- **Duration**: `0`
- **TickInterval**: `0`
- **MaxStacks**: `1`

**注意**: 概率值0.25会通过BuffFactory自动设置到Buff.Probability字段，在BuffCmp.ProcessOnDeathBuffs中会检查概率。

### 2. 中毒Buff（间隔触发，每0.8秒造成攻击力20%的伤害，持续4秒）

**Buff配置：**
- **Id**: `10002`
- **Name**: "中毒"
- **Desc**: "每0.8秒受到攻击力20%的伤害"
- **BuffType**: `Damage` (3)
- **TargetType**: `Enemy` (2)
- **TriggerType**: `Interval` (2)
- **StatusId**: 0
- **ConditionParams**: `[]`
- **ValueParams**: `[0, 1, 0.2]`
  - `0`: DamageAmount (不使用固定伤害)
  - `1`: UseAttackerDamage (true，使用攻击者伤害)
  - `0.2`: AttackPercent (20%攻击力)
- **Duration**: `4` (持续4秒)
- **TickInterval**: `0.8` (每0.8秒触发一次)
- **MaxStacks**: `1`

## 代码修改说明

1. **TargetSelector系统**: 使用TargetSelector系统来选择目标，支持多种目标类型（Enemy, Friendly, Self, All, RandomEnemy, RandomAlly, specific）
2. **DamageEffect**: 支持AttackPercent参数，可以基于攻击者攻击力百分比造成伤害
3. **BuffCmp.OnDestroy**: 处理OnDeath触发的Buff
4. **BaseBuff.TriggerEffectPublic**: 公开方法，用于外部触发Buff效果
5. **BaseBuff.GetTargets()**: 使用TargetSelector获取目标列表

## 新的实现方式（使用TargetSelector）

现在不再使用ApplyBuffEffect，而是通过以下方式实现多目标施加Buff：

1. 在BuffConfig中配置TargetType和TargetParams
2. 在Effect中使用BaseBuff.GetTargets()获取目标列表（需要在Effect中访问BaseBuff）
3. 或者创建一个新的Effect类型，专门处理"对多个目标施加Buff"的功能

**注意**: 如果需要在Effect中访问BaseBuff，需要在BaseEffect中添加对BaseBuff的引用。

## 注意事项

1. 亡语Buff需要在UnitConfig或TowerConfig中配置，作为单位的被动技能
2. 中毒Buff的AttackPercent参数会基于施加Buff时的攻击者攻击力计算伤害
3. 搜索半径999表示全图搜索，可以根据需要调整
4. 目标数量2表示最多对2名敌人施加中毒Buff
