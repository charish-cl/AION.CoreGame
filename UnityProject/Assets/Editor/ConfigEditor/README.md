# 快速配置编辑器使用说明

## 概述
新的快速配置编辑器解决了原有配置编辑器的性能问题和用户体验问题，提供了更高效的配置编辑体验。

## 主要改进

### 1. 性能优化
- **EPPlus直接读取**: 使用EPPlus库直接读取Excel文件，避免重复解析
- **虚拟滚动**: 支持大数据量配置，只渲染可见区域
- **数据缓存**: 智能缓存机制，避免重复加载

### 2. 用户体验改进
- **横向Excel布局**: 类似Excel的横向表格布局，更直观
- **友好字段名**: 显示注释中的中文名称，而非变量名
- **直接新建**: 一键新建TbBullet和TbModel，无需输入名称
- **实时搜索**: 快速搜索过滤配置数据

### 3. 功能特性
- **多表支持**: 支持所有Tb开头的配置表
- **快速切换**: 下拉选择不同配置表
- **详情面板**: 右侧显示选中行的详细信息
- **智能ID生成**: 自动为新配置生成合适的ID

## 使用方法

### 打开编辑器
1. 在Unity菜单中选择 `Tools/Fast Config Editor`
2. 编辑器会自动加载Excel配置或运行时配置

### 基本操作
1. **选择表**: 在顶部下拉框选择要编辑的配置表
2. **查看数据**: 主界面显示表格数据，点击行选择
3. **编辑数据**: 直接点击单元格进行编辑
4. **搜索**: 点击"搜索"按钮，输入关键词过滤数据

### 新建配置
1. **新建子弹**: 点击"新建子弹"按钮，输入ID和名称即可
2. **新建模型**: 点击"新建模型"按钮，输入ID、名称和模型路径
3. **自动切换**: 新建后会自动切换到对应表并添加新配置

### 保存和刷新
1. **保存**: 点击"保存"按钮保存当前修改
2. **刷新**: 点击"刷新"按钮重新加载数据

## 技术特点

### 虚拟滚动
- 每页显示50条数据
- 支持翻页导航
- 大幅减少内存占用

### 智能缓存
- 5分钟缓存有效期
- 自动失效机制
- 避免重复加载

### 表结构解析
- 自动识别Luban表结构
- 读取字段注释作为显示名
- 支持枚举类型编辑

## 注意事项
- 确保Excel文件路径正确配置
- 大表编辑时建议使用虚拟滚动
- 保存前确认数据正确性
- 定期备份配置数据
